# Retail Sales Data Analysis

## Overview
This project explores retail sales data using Python to understand sales performance, identify trends, and extract meaningful business insights.

## Objectives
- Inspect and understand the dataset.
- Clean data by handling missing values and duplicate records.
- Perform exploratory data analysis (EDA).
- Calculate total sales and analyze sales performance.
- Identify top-selling products.
- Analyze monthly sales trends.
- Explore country-wise sales patterns.
- Visualize data to identify patterns and outliers.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Feature creation
4. Exploratory data analysis
5. Data visualization
6. Business insights

## Key Learnings
- Data cleaning and preprocessing
- Exploratory data analysis
- Statistical analysis
- Data visualization
- Extracting insights from sales data

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Update the dataset path if required.
5. Run the notebook cells in sequence.
